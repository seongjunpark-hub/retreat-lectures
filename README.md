# 수련회 선택특강 수강신청

- `index.html` — 학생용: ① 입장 화면(이름·휴대폰·가등록/등록·출신 지구) → ② 특강 목록에서 신청
- `admin.html` — 관리자용: 특강 카드 목록 + [새 특강 등록], 신청 현황/CSV, 신청 설정 (학생 화면 하단 '간사·관리자 로그인' 링크로도 이동)
- `schema.sql` — Supabase 데이터베이스 설정
- `config.js` — Supabase 주소/키

## 설정 순서 (약 15분)

1. **Supabase 새 프로젝트** 만들기 (기존 간사 앱과 분리 추천)
2. **SQL Editor**에 `schema.sql` 전체 붙여넣기 → 맨 아래 관리자 이메일을 본인 것으로 바꾸고 **Run**
3. **Authentication > Users > Add user** 에서 같은 이메일·비밀번호로 사용자 생성 (Auto confirm 체크)
4. **Project Settings > API** 의 Project URL, anon key 를 `config.js` 에 붙여넣기
5. 이 폴더를 **Vercel**에 업로드 (GitHub 연결 또는 `vercel` 명령) → 배포
6. `주소/admin.html` 로 로그인 → 특강 등록 → **신청 설정**에서 시작 시각 입력
7. 학생들에게 `주소` 공유

## 이미 예전 schema.sql 을 실행했다면

새 `schema.sql` 을 SQL Editor에서 한 번 더 Run 하면 됩니다. 기존 데이터는 유지돼요.

## 동작 방식

- 신청 시작 전엔 특강 목록과 카운트다운만 보이고 버튼은 잠겨 있음
- 시작 시각 판단은 **서버 시간** 기준 (학생 폰 시계를 바꿔도 소용없음)
- 정원 체크는 DB에서 강의별로 줄을 세워 처리 → 동시에 몰려도 정원 초과 없음
- 학생 1명당 특강 1개만 신청 가능 (이름+번호 기준) — 바꾸려면 취소 후 다시 신청
- 학생은 마감 전까지 직접 취소 가능, 빈자리는 바로 다음 사람에게
- 강사 연락처는 관리자 화면에만 보임
- 신청 현황 탭에서 출신 지구 × 가등록/등록 인원표 확인 (학생 1명은 1번만 집계)
- 입장 코드를 설정하면 코드를 아는 사람만 신청 가능 (외부인/장난 방지)

## 업데이트 방법

GitHub 저장소에서 바뀐 파일(index.html, admin.html, style.css)을 다시 올리면 Vercel이 자동으로 새로 배포해요. config.js 는 그대로 두면 됩니다.
